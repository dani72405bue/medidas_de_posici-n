# Medidas_de_posición
programa parar la materia de estadistica 2026

# Funcionamiento del programa 

- El programa bajo el permiso del profesor de estadística (el profe Mauricio), cosiste en el tema de "medidas de posición" para solucionar el problema de hacerlo con lápiz y papel y comprender el entendimiento del tema mediante un lenguaje de programación usado 100% organico con Python, introducimos un máximo de 150 valores y en la terminal (lugar de ejecucion del programa) podemos escoger que queremos buscar, todas las opciones o salirnos del progama, ya sean cuartiles, deciles y porcentiles.

 Acá paso a paso: 
- Nos piden la cantidad de datos para empezar a programar.
- Una vez puestos nos dirá que opción queremos calcular. Dependiendo de los que queremos hallar ponemos el número.
- nos arrojará el resultado directamente y el programa se reiniciará pidiendonos una vez más la cantidad de datos.
